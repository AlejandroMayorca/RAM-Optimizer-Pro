# Changelog

## 3.0.0 — 2026-10-11

**Español**
- Interfaz completamente rediseñada con panel en tiempo real, gráfica de actividad y temas oscuro, claro y automático.
- Tres niveles de limpieza: Rápida, Equilibrada y Profunda.
- Limpieza automática inteligente y limpieza programada.
- Protección de la aplicación activa y de los procesos críticos del sistema.
- Gestor de procesos con búsqueda, agrupación y exclusiones.
- Porcentaje de RAM en vivo en la bandeja del sistema y notificaciones nativas.
- Inicio con Windows y apertura sin avisos de UAC.
- Nuevo instalador con actualización automática desde versiones anteriores.
- Corregido: el inicio automático se detenía a las 72 horas y no arrancaba con batería.

**English**
- Fully redesigned interface with a real-time dashboard, activity chart and dark, light and automatic themes.
- Three cleaning levels: Quick, Balanced and Deep.
- Smart auto-clean and scheduled cleaning.
- Protection for the active app and critical system processes.
- Process manager with search, grouping and exclusions.
- Live RAM percentage in the system tray and native notifications.
- Starts with Windows and opens without UAC prompts.
- New installer that upgrades previous versions automatically.
- Fixed: autostart stopped after 72 hours and did not start on battery power.
